DESKRIPSI
---------
Platform web untuk fotografer profesional mengelola proses
photo culling (seleksi foto) bersama klien. Fotografer upload
foto, klien review dan pilih foto yang diinginkan, fotografer
edit, lalu upload hasil editan final untuk didownload klien.
Semua dilakukan online tanpa kirim file fisik.


TECH STACK
----------
Frontend        : React 18 + Vite + Tailwind CSS
Backend         : Node.js + Express
Database        : PostgreSQL 16
Object Storage  : MinIO (self-hosted, S3-compatible)
Image Proxy     : Node.js + Sharp (resize, watermark, WebP)
AI Quality Svc  : Python 3 + FastAPI + OpenCV
Deployment      : Docker Compose di Ubuntu 24.04 VPS
Repository      : https://github.com/iicatt/youngscreative-photo-culling

ALUR APLIKASI
-------------
1. Fotografer buat sesi baru (nama sesi + nama klien)
2. Fotografer upload foto RAW ke sesi
3. AI otomatis analisis foto (blur, mata tertutup, duplikat)
4. Fotografer bagikan Client Link ke klien
5. Klien buka link → pilih mode:
      a. Pilih Sendiri  — klien review & pilih sendiri semua foto
      b. Sudah Dipilihkan — fotografer sudah kurasi, klien tinggal setuju
6. Klien tandai setiap foto: Ready to Edit / Needs Revision / Reject
7. Fotografer edit foto terpilih di Lightroom / software edit
8. Fotografer upload hasil editan final ke sesi
9. Sesi otomatis berubah ke fase Pasca-Edit
10. Klien buka link → tab "Hasil Edit Final" otomatis terbuka
11. Klien preview, beri tanggapan (Setuju/Perlu Revisi), unduh ZIP


HALAMAN / ROUTES
----------------
FOTOGRAFER (perlu login):
  /                        Dashboard — overview sesi + stats
  /sesi/:id                Detail sesi + grid foto + AI culling
  /sesi/:id/upload         Upload foto RAW
  /login                   Login fotografer

KLIEN (akses via token, tanpa login):
  /k/:token                Landing — pilih mode (Pilih Sendiri / Sudah Dipilihkan)
  /k/:token/galeri         Galeri foto + tab Hasil Edit Final
  /k/:token/foto/:id       Detail foto + form seleksi


FITUR FOTOGRAFER
----------------
- Dashboard dengan statistik total foto, ready to edit, needs review
- Buat sesi baru per klien
- Upload foto massal (drag & drop, max 100 file, max 200 MB/file)
- Grid foto dengan filter: All, Issues, Blur, Eyes, Similar
- AI Culling otomatis:
    * Deteksi blur (Laplacian variance, threshold: 100)
    * Deteksi mata tertutup (Eye Aspect Ratio, threshold: 0.21)
    * Deteksi foto duplikat/mirip (Perceptual Hash, threshold: 5)
    * Progress bar realtime
- Mark foto sebagai Revision secara massal
- Re-analyze foto dengan AI
- Mode panel "Sudah Dipilihkan" — fotografer bisa pre-kurasi foto
- Upload hasil editan final (JPG, PNG, WebP, TIFF)
- Tombol "Tandai Selesai Edit" → fase berubah ke Pasca-Edit
- Export Lightroom (ZIP + XMP sidecar) untuk foto siap edit
- Salin Client Link ke clipboard (dengan fallback untuk HTTP)
- Tutup sesi


FITUR KLIEN
-----------
- Akses via token link (tanpa perlu daftar/login)
- Pilih mode review (permanen, tidak bisa diubah):
    * Pilih Sendiri  — review semua foto, tandai sendiri
    * Sudah Dipilihkan — lihat kurasi fotografer, beri persetujuan
- Gallery foto dengan watermark CFC (via Image Proxy)
- Filter foto berdasarkan status
- Klik foto untuk review detail
- Tandai foto: Ready to Edit / Needs Revision / Reject
- Tulis catatan untuk fotografer per foto
- Tab "Hasil Edit Final" (muncul setelah fase Pasca-Edit):
    * Preview hasil editan
    * Beri tanggapan: Setuju / Perlu Revisi
    * Unduh semua hasil edit dalam ZIP
- TIDAK BISA download foto RAW asli (keamanan)


KEAMANAN
--------
- Foto RAW asli TIDAK bisa didownload klien
- Foto ditampilkan dengan watermark via Image Proxy
- Klien hanya bisa download hasil edit final (ZIP)
- Download diblokir di fase Pra-Edit
- Akses klien via token unik per sesi
- Fotografer akses via JWT (expire 7 hari)
- Semua password di-hash dengan bcrypt (cost 12)

PERINTAH BERGUNA DI SERVER
---------------------------
# Lihat semua container
docker compose -f /opt/youngscreative/docker-compose.prod.yml ps

# Lihat log realtime
docker compose -f /opt/youngscreative/docker-compose.prod.yml logs -f

# Restart satu service
docker compose -f /opt/youngscreative/docker-compose.prod.yml restart backend

# Masuk ke database
docker exec -it yc_postgres psql -U ycuser -d youngscreative

# Reset password user
docker exec yc_backend node -e "require('bcrypt').hash('password123',12).then(h=>process.stdout.write(h))"
